마인약품 요율표

전달받은 개인 코드를 입력해 주세요.
처음 한 번만 입력하면 이 폰에서 계속 쓸 수 있어요.

코드는 처음 입력한 폰 1대에서만 쓸 수 있어요.

설치 방법 그림으로 보기

아이폰은 먼저 홈 화면에 추가한 뒤,
홈 화면의 마인약품 아이콘에서 코드를 입력해 주세요.

  1. 화면 아래(또는 위)의 공유 버튼 을 누르세요.
  2. 목록에서 홈 화면에 추가를 누르세요.
  3. 홈 화면에 생긴 마인약품 아이콘을 눌러 코드를 입력하세요.

사파리에서 코드를 먼저 넣으면 홈 화면 앱이 다른 기기로 인식돼 잠길 수 있어요.

설치 방법 그림으로 보기

카카오톡 안에서는 앱으로 설치할 수 없어요.
휴대폰 브라우저로 열어 주세요.

브라우저로 열기

버튼이 안 되면 오른쪽 위 ⋮ (또는 아래 공유) 메뉴에서
“다른 브라우저로 열기”를 눌러 주세요.
