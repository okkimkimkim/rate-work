마인약품 앱 설치 방법

처음 한 번만 하면 돼요. 2~3분이면 끝나요.

꼭 이 순서대로! 사파리에서 코드를 먼저 넣으면 앱이 잠길 수 있어요. 홈 화면에 먼저 추가한 다음, 아이콘을 눌러 코드를 넣으세요.

  1. 카톡 링크를 사파리로 열기

    카톡에서 링크를 누른 뒤, 오른쪽 위(또는 아래) ⋯ 메뉴 → Safari로 열기를 누르세요.

    ⋯
    링크 복사
    Safari로 열기
    공유
  2. 공유 버튼 누르기

    사파리 화면 아래쪽 가운데의 네모에 위 화살표 모양 버튼이에요.

    ‹›□⧉
  3. 홈 화면에 추가

    목록을 아래로 내려 홈 화면에 추가를 누르고, 오른쪽 위 추가를 누르세요.

    복사
    읽기 목록에 추가
    홈 화면에 추가 ⊞
    즐겨찾기 추가
  4. 홈 화면의 아이콘 누르기

    바탕화면에 생긴 마인약품 아이콘을 눌러 앱을 여세요.

    마인약품
  5. 개인 코드 입력

    전달받은 코드를 넣고 시작하기를 누르면 끝!

    마인약품 요율표● ● ● ● ● ●시작하기
  1. 카톡 링크를 크롬으로 열기

    카톡에서 링크를 누르면 나오는 화면에서 브라우저로 열기 버튼을 누르거나, 오른쪽 위 ⋮ → 다른 브라우저로 열기.

    ⋮
    링크 복사
    다른 브라우저로 열기
    공유
  2. 개인 코드 입력

    전달받은 코드를 넣고 시작하기를 누르세요.

    ⋮
    마인약품 요율표● ● ● ● ● ●시작하기
  3. 앱 설치

    화면의 앱 설치 버튼을 누르거나, 오른쪽 위 ⋮ → 앱 설치(또는 홈 화면에 추가) → 설치.

    ⋮
    새 탭
    북마크
    앱 설치
    공유
  4. 홈 화면 아이콘으로 열기

    다음부터는 바탕화면의 마인약품 아이콘만 누르면 바로 열려요. 코드를 다시 넣을 필요 없어요.

    마인약품

설치 후에는 인터넷이 잠깐 끊겨도 마지막으로 받은 요율표를 볼 수 있어요.

· 코드는 처음 입력한 폰 1대에서만 쓸 수 있어요. 다른 사람에게 알려주지 마세요. · 폰을 바꾸거나 앱을 지웠다가 다시 깔면 잠길 수 있어요. 그때는 연락 주세요. ← 앱으로 돌아가기
